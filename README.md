# 💰 Planej.ai - Controle Financeiro

Aplicação web desenvolvida para gerenciamento de finanças pessoais, permitindo o cadastro de entradas e saídas, cálculo automático de saldo em tempo real e persistência de dados local.

## 🚀 Tecnologias Utilizadas

- **HTML5:** Estruturação semântica e acessível (com uso de `sr-only`).
- **CSS3:** Estilização modularizada, variáveis customizadas (`--var`), Flexbox e design responsivo (Mobile-First).
- **JavaScript (Vanilla):** Manipulação avançada do DOM, métodos modernos de array (`filter`, `reduce`), delegação de eventos e API `Intl.NumberFormat`.
- **LocalStorage:** Persistência de dados direto no navegador do usuário.

## 📱 Funcionalidades

- Cadastro, edição e exclusão de movimentações financeiras.
- Filtro por tipo (Entradas e Saídas).
- Cálculo dinâmico de Saldo Total.
- Sistema de feedback visual interativo (Toasts).
